# Roadmap

Milestones follow the master specification. A milestone is complete only with an
executable, automated tests, and captured real-run evidence.

## A — Native model viewer (DONE, verified)

- Loads MDX + BLP directly from local 1.27d MPQs (no Blender/GLB).
- Skinned animation, material layers with WC3 blend/depth states, team color.
- Evidence: `artifacts/footman_stand.png`, `footman_walk_*.png`, `footman_attack_*.png`,
  `footman_death.png` (death pose collapses correctly), `footman_defend.png`.
- Tests: sampler math, pivot/transform hierarchy, blend-state mapping, real Footman
  parse + skinning + animation-motion + texture resolution (see `dotnet test`).
- Diagnostic CLI: `War3Engine.Inspector model`, `blp`, `pose`, `assets`, `extract`.

## B — Complex model rendering (in progress)

Done first-pass: multi-layer materials, all seven filter modes mapped to GPU states,
geoset animation alpha/color, per-layer alpha tracks, texture-id tracks.
Remaining: billboard nodes, UV texture animation, ParticleEmitter/ParticleEmitter2,
RibbonEmitter, priority-plane render queue, team glow tinting, attachment diagnostics.

## C — Static map viewer (core done, fidelity gaps)

Done: W3I/W3E/DOO/Units parse; terrain mesh with 7 Cityscape textures; tiered heights;
doodad/destructible placement with variations and destructible replaceable textures;
map inspector (`mapdata`); screenshots of overview and ground level on the fixture map.

Remaining: WC3 ground texture splat blending, cliff/ramp models, water surfaces,
and object-data overrides for custom maps. Tracked as the C-polish task.

Note: the fixture map is protected — `war3map.j` / `war3map.lua` are absent while
`war3map.wtg`/`wct` exist. Script execution for this map is therefore deferred to E
with an alternate controlled fixture.

## D — Interactive runtime

Units, selection, orders, movement, pathing, combat over the fixed-step simulation.

## E — Scripted map execution

JASS parser/VM, natives, triggers, timers; Lua later. Requires a map with an
accessible script (fixture TBD).

## F — Expanded compatibility

UI/FDF, audio, fog of war, campaign, multiple map/version fixtures.

## G — Multiplayer and modern formats

Only after single-player determinism; CASC/Reforged as a separate capability.

## Engineering rules

- Every parser validates bounds and offsets; malformed input throws typed errors.
- No silent fallbacks for unsupported rendering; diagnostics list unresolved assets.
- Screenshots are generated by `War3Engine.Client --screenshot` (deterministic frame).
